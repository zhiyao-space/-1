# 需求：个人主页 + 面具系统

日期：2026-09-29
来源：用户口头需求（批次4 验收后追加）

## 需求描述

新增"主页"应用（用户个人主页），高自由度自定义；配套"面具"系统切换与 AI 聊天时的用户身份。

### 1. 个人主页（高自由度编辑）

- 头像、主页背景：从相册导入图片（IndexedDB 存储）
- 资料字段全部自由编辑：昵称、性别（自由文本）、年龄、IP属地（自由文本）、个性简介
- 标签：自由增删（上限 10 个）
- 数据栏：关注 / 粉丝 / 互关数值可自由设定；作品数量随作品列表自动统计
- 作品：用户自建卡片（标题 + 简介 + 可选图片），可增删改

### 2. 面具系统（AI 身份切换）

- 面具 = 一个可切换的聊天身份：身份名 + 头像 + 身份设定（自由文本，AI 读取）
- 可新建 / 编辑 / 删除 / 佩戴（激活）/ 摘下
- 佩戴中面具注入 AI 聊天 prompt（单聊 + 群聊）：
  - 用户发言以面具身份名署名
  - 系统提示注入【关于对话对象（用户）】：面具身份 + 设定 + 主页资料（性别/年龄/IP属地/标签/简介）
- 未佩戴面具时，AI 按主页资料 + 昵称认识用户

## 验收要点

- 桌面出现"主页"图标（首位）
- 主页资料编辑保存后刷新仍在（ksc:profile）
- 佩戴面具后发起聊天，AI 以面具身份称呼/认知用户
